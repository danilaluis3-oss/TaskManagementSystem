# 📋 Task Management System

An Android Task Management application developed as my Bachelor's Degree project.

## 📱 Overview

Task Management System is a modern Android application that helps users organize daily activities, manage tasks efficiently and increase productivity through reminders and priorities.

## ✨ Features

- ✅ Create tasks
- ✏️ Edit tasks
- 🗑 Delete tasks
- ⭐ Set task priorities
- 🔔 Notifications and reminders
- 📅 Due dates
- 💾 Local storage using Room Database
- 🎨 Modern interface built with Jetpack Compose

## 🛠 Technologies Used

- Kotlin
- Jetpack Compose
- Room Database
- WorkManager
- Material Design 3
- Android Studio

## 📦 Installation

1. Download the latest APK from the **Releases** section.
2. Install the APK on your Android device.
3. Allow installation from unknown sources if requested.
4. Launch the application.
